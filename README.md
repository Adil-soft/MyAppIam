# Módulo de Identificación Móvil mediante Códigos SKQR

Aplicación desarrollada en **Kotlin** como parte del proyecto académico de un sistema de control de acceso con inteligencia bimodal utilizando codigos SKQR 
y reconocmiento facial.  
Este módulo permite la **identificación y validación de usuarios** mediante **códigos SKQR dinámicos**, que pueden ser escaneados para verificar permisos de acceso.

## Contexto del proyecto
Este desarrollo forma parte del **Trabajo Fin de Grado** en Ingeniería Informática (Escuela Politenicia Superior de Córdoba, 2024), enfocado en la creación de un sistema inteligente de control de acceso con tecnologías móviles y web.

El sistema completo integra:
- Reconocimiento facial (módulo web)
- Identificación móvil por códigos QR (este proyecto)
- Backend en PHP y base de datos MySQL

## Funcionalidades principales
- Generación y lectura de códigos QR únicos por usuario, basados en una secuencia matemática para garantizar unicidad y seguridad.
- Comunicación con servidor remoto mediante API REST.
- Interfaz adaptable y ligera, desarrollada con Android Studio.

## Tecnologías utilizadas
- Kotlin / Android Studio  
- PHP (backend)  
- MySQL (base de datos)  
- HTML / JavaScript / CSS
